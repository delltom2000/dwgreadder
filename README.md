# 图阅 · DWG 阅读器

一个在本机运行的二维 DWG 阅读器。图纸内容在浏览器 Web Worker 中解析，不发送到外部服务，也不会修改原文件。

## 启动

需要 Node.js 20.19+ 或 22.12+。首次使用先在项目目录运行 `npm ci`。Windows 用户随后双击 **启动阅读器.cmd**，浏览器会打开 <http://127.0.0.1:5173/>。

也可在本目录运行：

```powershell
npm run dev
```

启动器仅监听 `127.0.0.1`，后台服务日志位于 `.local/server.log` 和 `.local/server-error.log`。关闭浏览器后本地服务继续运行。开发时可以在运行 `npm run dev` 的终端按 Ctrl+C 停止。

## 三个核心功能

1. **打开文件**：点击右上角“打开图纸”，或把 DWG 拖入窗口。支持 100 MB 以内的文件，读取过程中可以取消。
2. **查看主图**：按住鼠标左键拖动平移，滚轮以鼠标位置为中心缩放。双击或按 F / Home 显示全图。
3. **结构定位**：左侧按图层、图块、文字浏览和搜索。展开图块可查看嵌套对象；点击项目自动定位并高亮，文字定位会保留周围环境。图层右侧眼睛可临时隐藏图层。右上角可切换模型空间和文件内已有的布局记录。

快捷键：Ctrl+O 打开文件，`/` 搜索；焦点在主图时 `+` / `-` 缩放，Esc 取消图中高亮。

界面和主图采用浅蓝色底色，原图浅色线条会自动调整为更适合浅色背景的颜色，保持可读性。

右上角“最近打开”自动保存成功读取过的 DWG，刷新或关闭页面后可在同一浏览器、同一地址直接重新打开。历史记录使用 IndexedDB 保留图纸副本，最多 10 份、合计 250 MB，超出时移除较早的记录。可单独移除或清空。历史副本反映上次读取的版本，原文件有修改时应重新选择文件；清理浏览器数据也会清除历史，浏览器存储不可用或空间不足时会提示。

指定示例文件路径保存在被 Git 忽略的 `.local/sample-path.json` 中。双击启动器后首页可直接打开这份文件，文件本身没有复制进项目。开发终端如需同样入口，可以先设置 `$env:DWG_SAMPLE='完整DWG路径'` 再运行 `npm run dev`。

## 读取范围与限制

这是轻量阅读版本，支持直线、多段线及凸度圆弧、圆、圆弧、椭圆、样条曲线、文字/属性文字、嵌套图块和已有标注图块。处理图块基点、二维旋转缩放、继承图层以及标注图块插入偏移。

- 图案填充目前显示边界；实体填充显示实心区域，多环填充的孔洞可能不精确。
- WIPEOUT 遮罩、外部图片、三维实体、自定义代理实体、布局视口的模型投影尚不支持。布局切换仅显示该布局自身的实体。缺少外部参照内容时不会自动寻找其他文件。
- 使用系统中文字体替代 CAD 的 SHX 字体，复杂多行文字的格式、宽度、字间距和线型/线宽可能与 AutoCAD 不一致。
- 解析告警和未完整显示的对象会汇总在左下角，点击状态可查看详情；不能将此版本视为 AutoCAD 的精确打印或审图替代品。

已使用提供的 128 户型 DWG 检查模型和布局的读取、搜索“客厅”后定位、拖动、缩放及错误文件提示。该文件的解析引擎返回告警码 68（未处理的类和数据越界），因此保留兼容提示。

## 开发和验证

```powershell
npm test
npm run build
npm run preview
```

几何测试覆盖嵌套图块坐标、标注偏移、模型/布局隔离、隐藏实体、循环引用及圆弧。`scripts/browser-check.mjs` 是本机浏览器回归脚本，默认使用 Playwright 安装的 Chromium，也可通过 `PLAYWRIGHT_EXECUTABLE_PATH` 环境变量指定浏览器。截图和检查结果保存在 `.local/`。

源码：`src/geometry.ts` 构建结构和坐标；`src/parser.worker.ts` 解析 DWG；`src/viewer.ts` 绘制与导航；`src/main.ts` 组织界面。

## 私有资料保护

本仓库只保存源码、测试和通用文档。DWG/DXF、图纸副本、截图、提取数据、历史记录、日志与凭据均不上传。上传前运行 `npm run check:upload` 检查 Git 暂存区。该检查是额外防线，不能替代提交内容的人工核对。
